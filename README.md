# 3D 晶体结构与晶格缺陷分析工具

React + Vite + TypeScript + React Three Fiber 的材料科学可视化基础项目，用于展示面心立方晶格、空位缺陷、替位缺陷与刃型位错。

## 当前能力

- 三维晶格原子与最近邻连接
- 空位、替位和刃型位错模型切换
- 晶胞数量调整
- 晶面透明度调整
- 缺陷指标展示
- 三维旋转、缩放和结构观察
- 统一射线拾取原子，避免为每个原子绑定独立点击事件
- 两点距离和三点夹角（第二点为顶点）测量覆盖层
- 显示选中原子的晶格索引坐标与当前场景三维坐标
- 点击空白、已选原子、按 Esc 或使用重置按钮取消测量
- 点击/拖拽通过位移阈值区分，旋转视角不会误选原子
- 晶胞数量或缺陷模型改变后自动清理失效选择
- 结构快照操作入口

## 启动

```bash
npm install
npm run dev
```

当前使用内置演示晶格数据，后续可接入 CIF 文件解析、晶面选择、晶格常数计算、位错密度分析、XRD 辅助数据和真实分子动力学结果。
